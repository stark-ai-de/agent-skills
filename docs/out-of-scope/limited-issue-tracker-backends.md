# Limited Issue Tracker Backends

First-class issue tracker automation is limited to common tools and local markdown until real demand justifies more.

Skills may document GitHub Issues and local markdown workflows by default. Other trackers can be described in downstream `docs/agents/issue-tracker.md` files, but this public catalog should not ship backend-specific write automation without clear maintainer demand and explicit safety rules.

Any live mutation of issues, labels, assignments, or project boards requires explicit user authorization.
