# Out-of-Scope Notes

Use out-of-scope notes for stable repository boundaries that are useful to future maintainers but not architectural enough for an ADR.

Write an ADR when the decision changes format, validation, publishing, repository layout, or supported runtime policy. Write an out-of-scope note when the decision rejects a class of additions, narrows scope, or explains why a tempting feature does not belong in the public catalog right now.

- [No personal private skills](no-personal-private-skills.md)
- [No mega-agent skill](no-mega-agent-skill.md)
- [Limited issue tracker backends](limited-issue-tracker-backends.md)
