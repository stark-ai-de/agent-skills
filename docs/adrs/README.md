# ADR files

Every numbered decision in this directory is a linked Short, Long, and Guide triplet. Long is canonical; Short is the normal human-readable entry point; Guide is non-normative application and verification help.

For metadata, naming, authoring, accepted-decision locks, status, supersession, and the grouped index, see [`docs/adrs.md`](../adrs.md). New records start from the three `TEMPLATE.*.md` files or `pnpm run adr:new`.
