## Limits and unresolved capabilities

Refresh the relevant official sections for file upload/download limits, HTTP response-size limits, supported updates, and static-hosting options. Streaming does not remove the documented size limits.

The referenced platform page does not establish runtime secret injection, transaction guarantees, invocation CPU/memory/time quotas, pricing/SLA, scheduler support, or backup/restore commands. Treat these as unresolved capabilities, not affirmative promises or proof of impossibility. If a requested design relies on one, identify the missing evidence and pause that dependent operation. Continue work that does not depend on it.

CLI source can resolve documented command behavior; it cannot establish unobserved server behavior. Remote execution with synthetic context cannot qualify platform authentication. Offline evaluation cannot qualify live hosting, database semantics, API delivery, or performance.
