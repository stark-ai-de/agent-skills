# Skill Maintenance

Reviewed workflows for choosing and maintaining agent capabilities. Third-party helper skills live project-locally under `.agents/skills/`, outside this public catalog.

| Skill                                                       | Description                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`jev-capability-advisor`](jev-capability-advisor/SKILL.md) | Recommend relevant available skills or MCP tools for a supplied task using TypeSafe Jev. Use when the user asks which installed capabilities fit a task, compares selection quality, or integrates reusable capability advice into a host. Ordinary task execution continues through the client's own discovery. |

Read the [guide and qualification](../../docs/skills/jev-capability-advisor/README.md) for installation, features and measurement boundaries.
