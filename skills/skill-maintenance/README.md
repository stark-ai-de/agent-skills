# Skill Maintenance

Skills for writing, installing, validating, curating, and releasing public Agent Skills.

Third-party helper skills live outside the public catalog under `.agents/skills/`.

| Skill                                                               | Description                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`skill-authoring-review`](skill-authoring-review/SKILL.md)         | Create or review Agent Skills with correct SKILL.md frontmatter, trigger descriptions, concise workflow design, progressive disclosure, references, scripts, assets, safety rules, and installability. Use when writing a new skill, improving an existing skill, or validating a public skills repo. |
| [`skill-installation-support`](skill-installation-support/SKILL.md) | Help install, list, update, remove, or troubleshoot Agent Skills using the Vercel skills CLI. Use when the user asks about npx skills add, installing a whole repo, installing one skill, global vs project installs, symlink vs copy, or Codex/Claude/Cursor agent targets.                          |
| [`skill-repo-curator`](skill-repo-curator/SKILL.md)                 | Maintain a public Agent Skills repository. Use when updating skill catalogs, validating SKILL.md files, preparing a release, deprecating skills, reviewing install commands, checking README consistency, or keeping a skills repo ready for npx skills installation.                                 |
