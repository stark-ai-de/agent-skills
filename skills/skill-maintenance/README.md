# Skill Maintenance

Reviewed workflows for choosing and maintaining agent capabilities. Third-party helper skills live project-locally under `.agents/skills/`, outside this public catalog.

| Skill                                                       | Description                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`jev-capability-advisor`](jev-capability-advisor/SKILL.md) | Recommend available skills or MCP tools using TypeSafe Jev, or explicitly choose one next skill. Use when the user requests capability advice, candidate inspection, selection evaluation, or reusable host integration. Native client selection remains the default and fallback. |

Read the [guide and qualification](../../docs/skills/jev-capability-advisor/README.md) for installation, features and measurement boundaries.
