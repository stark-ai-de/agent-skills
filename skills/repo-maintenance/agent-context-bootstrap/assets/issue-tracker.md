# Issue Tracker

## Tracker

Document the issue tracker used by this repository.

## Live Mutation Rules

- Ask before creating, closing, labeling, assigning, or moving issues.
- Prefer draft issue bodies when the tracker or labels are unclear.
- Link validation evidence when changing issue state.

## Maintainer Rules

- Do not close, label, assign, or move issues without authorization.
- Prefer draft responses when reporter context is incomplete.
- Link code, docs, or validation evidence when changing issue state.

## Ready for Agent Work

An issue is ready when the expected outcome, scope, validation command, and constraints are clear.
