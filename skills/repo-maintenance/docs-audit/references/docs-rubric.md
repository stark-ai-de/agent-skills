# Docs Rubric

Review:

- First-screen clarity: what this is, who it is for, and why it matters.
- Installation path: exact commands and prerequisites.
- First success path: smallest useful example.
- Validation path: how users know setup worked.
- Contribution path: local workflow, style, and PR expectations.
- Safety: warnings for destructive actions, credentials, and public/private boundaries.
- Link health: internal links, anchors, and renamed files.
- Drift: commands and config examples match live files.
- Agent usability: repo rules and validation commands are easy for agents to find.
