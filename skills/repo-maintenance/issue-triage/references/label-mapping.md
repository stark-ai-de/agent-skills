# Label Mapping

Suggested generic labels:

| Category    | Labels                                            |
| ----------- | ------------------------------------------------- |
| Bug         | `bug`, `needs-reproduction`, `needs-info`         |
| Feature     | `enhancement`, `needs-design`, `needs-maintainer` |
| Docs        | `documentation`, `good-first-issue`               |
| Maintenance | `maintenance`, `tech-debt`                        |
| Security    | `security`, `private-report`                      |
| Agent-ready | `ready-for-agent`, `scoped`                       |
| Duplicate   | `duplicate`                                       |

Map these to the repository's actual labels before applying them.
