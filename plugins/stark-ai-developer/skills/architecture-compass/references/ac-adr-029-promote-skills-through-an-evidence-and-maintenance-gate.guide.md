## Review worksheet

| Dimension                  | Evidence | Revision/environment | Limitation | Disposition |
| -------------------------- | -------- | -------------------- | ---------- | ----------- |
| Activation and restraint   |          |                      |            |             |
| Outcome improvement        |          |                      |            |             |
| Safety and side effects    |          |                      |            |             |
| Utility and reuse          |          |                      |            |             |
| Install/host compatibility |          |                      |            |             |
| Maintenance ownership      |          |                      |            |             |

Use held-out or competing-skill cases when they can reveal over-activation. Keep subjective judgment auditable with a rubric and scenario evidence; do not report it as deterministic proof.
