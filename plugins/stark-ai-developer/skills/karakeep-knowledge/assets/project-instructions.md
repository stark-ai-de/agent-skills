## Shared agent knowledge

Use the globally installed `karakeep-knowledge` skill under this repository's adopted
knowledge ADR and private project policy. Run its read-only `check` once per session
and repository context. Reconcile eligible documents, separate drafts, factual
session reports and approved aggregates at meaningful completion. Repository
content remains authoritative and self-contained. Missing policy requires one-time
adoption; unavailable Karakeep does not block project work. Link the actual adopted
ADR here; this template alone does not authorize uploads.
