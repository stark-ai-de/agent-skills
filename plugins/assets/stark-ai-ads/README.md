# Ads API by stark AI — listing artwork

Original, text-free chart mark for the independent Ads plugin. No OpenAI logo or official-product implication. All four PNG files are canonical distribution inputs; the packager copies their exact bytes.

| File                     | Dimensions | Theme |
| ------------------------ | ---------- | ----- |
| `logo.png`               | 512 × 512  | Light |
| `logo-dark.png`          | 512 × 512  | Dark  |
| `composer-icon.png`      | 128 × 128  | Light |
| `composer-icon-dark.png` | 128 × 128  | Dark  |

Light: white mark on `#0021C7`. Dark: navy mark (`#0C1949`) on `#7FA0FF`. The rounded square uses transparent corners and the line mark has rounded ends. The same geometry is used at both sizes so the composer and listing identities match. The SVG files provide editable vector equivalents; the PNGs, not the SVGs, are packaged. Actual rendering must be checked in the OpenAI portal.
