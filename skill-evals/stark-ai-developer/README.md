# stark AI Developer plugin evaluations

This inventory is maintainer evidence for the one **stark AI Developer**
listing. It is not bundled into the portable or OpenAI runtime projections.
Cases are sanitized, deterministic review prompts and expected boundaries; they
do not claim a live ChatGPT, Codex, IDE, account, workspace, or public-directory
result.

Run the structural inventory check with:

```bash
npm run validate:plugin-evals
```

The repository-local marketplace is tested as a local portable Agent Plugin
catalog. OpenAI-native adapter packaging remains a separate submission flow.
Personal-marketplace and clean-clone fixtures are disposable temporary copies;
the test never writes to a user's home directory.
