# Clear Create Intent Selects And Proceeds

## Should Trigger

Yes.

## Prompt

Create a new animated README logo with Recraft and deliver the verified animation stack now.

## Deterministic Assertions

- contains: audit
- contains: create
- contains: transform
- contains: animate
- contains: Selected: create
- contains: provider approval remains separate
- not_contains: cost lookup complete
- not_contains: generated

## Expected Behavior

Expose all four workflows, announce `create` from the explicit new-logo outcome and write authority, then proceed without a redundant workflow confirmation. Report `Workflow`, `Source route`, `Selection`, `Write scope and protected originals`, `Provider state`, `Approval state`, `Motion readiness`, and `Animation delivery`. Provider evaluation is internal to `create`; live capability and cost may be inspected, but the exact paid batch and any tool installation remain separately approval-gated.
