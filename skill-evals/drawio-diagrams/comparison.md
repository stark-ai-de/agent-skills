# drawio-diagrams comparison

This maintainer-facing document reconstructs the two comparison tables published by
`Agents365-ai/drawio-skill` and adds this repository's `drawio-diagrams` skill. The
criteria are retained for comparability, but every cell is independently worded and
checked against the linked project documentation.

Audit date: **2026-07-15**. These are documented capabilities, not benchmark results.
`Conditional` means that the feature depends on an optional CLI, MCP service, local
index, network lookup, or host capability. Counts are project-reported rather than
independently reproduced.

## Interpretation

`Agents365-ai/drawio-skill` is broader: its current repository includes deterministic code/IaC/schema importers, Graphviz layout, sequence and C4 generators, style persistence, and more export/analysis formats. `stark-ai-de/agent-skills:drawio-diagrams` deliberately concentrates on architecture-content fitness, adaptive accessible presentation, self-contained icon use, surgical editing, semantic animation, and layered artifact validation with a much smaller runtime payload.

These tables do not prove an overall winner. Use the [published benchmark protocol](benchmark.md) for same-model, same-tool, blind paired evaluation; publish an outperformance claim only after its evidence and win threshold are satisfied.
