# Architecture Compass Evals

This folder stores promotion evidence for `architecture-compass`.

The skill should remain in the incubator until it demonstrates:

- correct activation for ADR-backed refactors, new-repo guardrails, PR drift reviews, backend runtime composition, and Next.js request-boundary work,
- correct non-activation for tiny edits, generic framework questions, dependency-only updates, and unrelated debugging tasks,
- improved rule extraction and safer file placement compared with a baseline run,
- public-safe output with no private source names or links,
- manageable reference size and maintenance cost.

## Suggested eval artifacts

- `activation-cases.md`: prompts and expected trigger result.
- `rubric.md`: grading rubric.
- `runs/YYYY-MM-DD-summary.md`: run summaries after manual or automated evaluation.
