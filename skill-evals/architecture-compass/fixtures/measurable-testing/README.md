# Measurable testing qualification fixtures

Repository-only synthetic targets for AC-ADR-059 through AC-ADR-062. These files are excluded from installed skills and generated plugin payloads. They qualify concrete mechanisms; the Markdown cases remain separate agent-behavior expectations.

The dependency graph is independent of the repository workspace. pnpm owns this lockfile; Bun runs Vitest 4.1.11 script bodies. TypeScript checks the tests and configuration. No root validation-framework migration or automatic target adoption is implied.

```bash
pnpm --dir skill-evals/architecture-compass/fixtures/measurable-testing install --frozen-lockfile
pnpm --dir skill-evals/architecture-compass/fixtures/measurable-testing run qualify --output /tmp/testing-qualification.json
```

`qualify` creates and removes a uniquely owned temporary target and dependency copy, runs bounded subprocesses, and writes only the explicitly selected receipt outside this fixture directory. Negative tests modify disposable files. The source fingerprint must remain unchanged. Persistent install is the separate command above. Reports, caches and Python bytecode never enter the source inventory.

## Evidence contract

- Rule coverage: small target cases directly exercise parsing, data inventory, resource boundaries, cache admission, metric truth and partition aggregation. Native public parsing remains importable without Vitest. Declared negative scenarios and outcomes are recorded in native results.
- Input coverage: sorted current Markdown/JSON discovery detects add/delete/rename, missing roots and empty domains. The root watch map and conservative affected selector cover filesystem inputs outside imports. Unknown changes broaden to the owner.
- Execution: unique resources, bounded children, cleanup failures and sequential/concurrent parity. Network denial is observed only at the instrumented boundary; OS/subprocess egress enforcement is unobservable, not claimed.
- Aggregation: independent expected file/case inventory; full source/config/lock/runtime/platform/project/input/run/attempt identity; no overlap, lost cases, foreign reports or unsuccessful predecessors. Native JSON is consumed only for this pinned profile, and native Vitest owns blob merging and reporters.
- Cache: a complete plugin-input key, no cross-trust restore, disposal confined to the owned cache and one visible recovery. Failed source assertions must remain failed in every state.
- Measurements: raw local process samples, median/range only, explicit denominators and provisional budgets. Summed process peak RSS is a conservative bound, not simultaneous peak memory. Installation, queues, hosted billing and transfer/storage economics are not inferred from local subprocess time. Governance adoption, measurement state and execution status stay separate.

## Maintenance

Requalify after dependency/runtime, config, project discovery, report format, transform inputs or concurrency changes. Do not rewrite dated receipts; capture a new run. Static provider regressions run through `pnpm run validate:architecture-compass`; this package exercises target mechanisms rather than asserting that agent behavior was executed. The CI workflow uploads an independently generated receipt for its exact commit.
