# Expected Standard Spec Sections

A passing standard output should include:

- frontmatter or clear title,
- goal,
- scope,
- non-goals,
- repo context,
- assumptions and open questions,
- requirements or acceptance criteria,
- source challenge summary,
- ADR gate result,
- one user-verification record of the reviewed revision and concrete writes,
- artifact paths and persistence status,
- actual persistence status kept separate from user approval,
- saved path, explicit completed chat-only delivery, or proposed path plus the requested-save blocker,
- design notes,
- task breakdown,
- validation commands,
- risks and rollout notes,
- done-when criteria,
- Claude Code execution prompt.

The exact headings may vary, but each item must be present and actionable.
