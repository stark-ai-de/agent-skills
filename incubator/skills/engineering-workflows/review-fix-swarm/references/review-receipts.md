# Reviewer receipts

Select the evidence route before starting each independent round. Verify host support and write permission for a private, task-owned evidence directory outside the target repository. Raw events, prompts, child output and transcripts can contain source or private data: restrict access (for example, POSIX directory mode 0700 and file mode 0600), retain them locally through reconciliation, and publish only sanitized evidence. Apply the user's retention and cleanup rules after reconciliation. Do not change sandbox or approval policies to enable capture.

For Codex CLI, inspect the installed `codex exec --help`; when supported, capture the complete `--json` stdout stream from process start to a private file and keep stderr separately. Use the host's native process/stream mechanism, check the capture process and exit status, and do not rely on a truncated tool response. `--ephemeral` does not persist session files; use it only when another authorized capture retains the required evidence through reconciliation. If native event fields omit required details, use a non-ephemeral private runtime transcript and inspect it before the review session ends or temporary storage is removed. If no authorized retention route is available, stop `BLOCKED` before launching reviewers.

For CLI versions whose JSONL schema exposes `item.completed` with `item.type` `collab_tool_call`, reconcile each role to its own completed `spawn_agent` item and `receiver_thread_ids`, then to a later completed `wait` item whose `agents_states` reports that child as `completed`. Verify each child's review output and source coverage separately. A spawn attempt, parent `turn.completed`, role label, or coordinator narrative is not evidence of child creation or completion. Check the installed version's schema rather than assuming these fields are stable; for example, see the [0.166.0 exec event schema](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/exec/src/exec_events.rs). If the event stream or transcript lacks identity or completion evidence, report `PARTIAL` and do not start a fixer based on unverified claims.
