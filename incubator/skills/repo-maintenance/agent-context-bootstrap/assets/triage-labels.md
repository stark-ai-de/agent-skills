# Triage Labels

Document labels agents may suggest for this repository.

## Label Source

List the source of truth for labels, such as `.github/labels.yml`, GitHub repository labels, or local maintainer docs.

## Suggested Label Groups

- Type: bug, feature, docs, maintenance, security, question.
- Status: needs-info, ready, blocked, duplicate.
- Difficulty: good-first-issue, help-wanted.

## Rules

- Agents may suggest labels unless the maintainer authorizes applying them.
- Do not invent labels as if they already exist.
- If no label source exists, draft labels in plain text and ask for confirmation.
