## Agent skills

- Use `$repo-health-audit` for repository maintenance audits.
- Use `$pr-review` for structured pull request reviews.
- Use `$issue-triage` for issue inbox cleanup.
- Use `$docs-audit` for documentation readiness checks.
- Use `$codex-spec-interviewer` before implementing fuzzy feature, refactor, migration, or architecture requests.
- Use `$handoff` before pausing long-running work.

Read `docs/agents/skill-routing.md`, `docs/agents/validation.md`, and `docs/agents/domain-docs.md` when they exist. Run the repository validation command before finalizing implementation work.
