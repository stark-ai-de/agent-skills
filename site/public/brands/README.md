# Operation badge marks

These assets are displayed only as small, subordinate category identifiers or
ChatGPT plugin link-outs. They are not this catalog's primary branding.

- `cursor-cube-light.svg` and `cursor-cube-dark.svg` are the unmodified 2D cube marks from the [Cursor brand kit](https://cursor.com/en-US/brand).
- `claude-spark-clay.svg` is the unmodified clay Spark mark from the [Anthropic press kit](https://www.anthropic.com/press-kit).
- `codex-color.svg` is the Codex color mark from [Lobe Icons](https://lobehub.com/icons/codex). Codex Operation badges use this local mark.
- `chatgpt-blossom-black.svg` and `chatgpt-blossom-white.svg` are the unmodified Blossom marks from the official [OpenAI brand logos package](https://cdn.openai.com/brand/openai-logos.zip) linked from [openai.com/brand](https://openai.com/brand/). Black is for light surfaces; white is for dark surfaces. On the colored primary CTA the pairing is inverted so the mark stays contrasted. Do not recolor, restyle, or combine the Blossom with the OpenAI wordmark here. The official artboard includes clear space; `.chatgpt-mark` optically scales the painted mark to adjacent text.
- The README listing shield at `docs/assets/chatgpt-plugin-badge.svg` uses the optically cropped white Blossom, then `ChatGPT` and the current plugin version. It is not an OpenAI Verified badge. OpenAI does not publish a README embed for Plugins Directory listings.

All product names and marks belong to their respective owners. Their presence describes skill compatibility or a link to ChatGPT and does not imply endorsement.
