# Operation badge marks

These assets are displayed only as small, subordinate category identifiers or
ChatGPT plugin link-outs. They are not this catalog's primary branding.

- `cursor-cube-light.svg` and `cursor-cube-dark.svg` are the unmodified 2D cube marks from the [Cursor brand kit](https://cursor.com/en-US/brand).
- `claude-spark-clay.svg` is the unmodified clay Spark mark from the [Anthropic press kit](https://www.anthropic.com/press-kit).
- The Codex badge references the unmodified OpenAI/ChatGPT app icon used on the [official Codex page](https://openai.com/codex/) because OpenAI does not currently publish a separate Codex vector package.
- `chatgpt-blossom-black.svg` and `chatgpt-blossom-white.svg` are the unmodified Blossom marks from the official [OpenAI brand logos package](https://cdn.openai.com/brand/openai-logos.zip) linked from [openai.com/brand](https://openai.com/brand/). Black is for light surfaces; white is for dark surfaces. On the colored primary CTA the pairing is inverted so the mark stays contrasted. Do not recolor, restyle, or combine the Blossom with the OpenAI wordmark here.
